We release a [technical report](https://arxiv.org/abs/2604.20987) introducing [COS-PLAY](https://wuxiyang1996.github.io/COSPLAY_page/), a co-evolution framework for long-horizon tasks where an LLM decision agent and a skill bank agent jointly improve through GRPO.
